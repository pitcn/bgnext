# BGNext 图标设计规范

## 目标

BGNext 使用一枚现代、精简的字母标志，同时服务插件平台、GitHub 和《魔兽世界》小地图入口。图标在 28 像素下必须仍能识别，不依赖细小文字、复杂纹理或游戏素材。

## 核心构图

- 主体为定制几何字母 `BG`，不是直接输入现成字体。
- `B` 与 `G` 通过共享笔画和负空间连接，形成一个完整轮廓。
- 字标置于铺满画布的深蓝方形底板内，不使用白边或透明圆角。
- 暖金色用于 `BG` 主体，青蓝色只用于 `G` 右侧的前进切口。
- 不显示额外的 `next` 文字；所有尺寸都只通过 `G` 右侧的青蓝前进切口表达 Next。
- 不加入金币、表格、盾牌、宝箱、武器、职业或《魔兽世界》图形。

## 视觉语言

- 风格：响应式 Lettermark、几何、负空间、简洁设计。
- 气质：现代、可靠、克制，避免电竞 Logo 和仿游戏徽章风格。
- 图形以三种主色为限，允许用于提升大图质感的轻微明暗变化，不使用发光、描边外框或照片素材。
- 字形应有清楚的外轮廓；内部负空间在 28 像素下不能闭合或粘连。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 深色底板 | `#0B111A` |
| 暖金主体 | `#F2BC45` |
| 青蓝强调 | `#21D4E6` |
| 单色浅色版 | `#F6F7F9` |

最终色值允许为视觉平衡做小幅调整，但必须保持深色底、暖金主体和青蓝单点强调的关系。

## 响应式版本

### 平台版

- 适用尺寸：256–1024 像素。
- 显示完整 `BG` 字标和青蓝切口，不增加说明性小字。
- 四周安全区不少于边长的 12%。

### 游戏图标版

- 适用尺寸：28、32 和 64 像素。
- 保留青蓝切口作为版本识别，不加入任何小字。
- 必要时扩大内部负空间并略微加粗主体，不能只对平台版机械缩小。

### 单色版

- 使用单一浅色或单一深色。
- 必须仅凭轮廓和负空间识别 `BG`，不能依赖金色与青蓝色的差异。

## 验收标准

- 在 16、28、32、64、256 和 1024 像素下分别检查。
- 28 像素下能在一秒内辨认出 `BG`，没有糊成一个色块。
- 转为灰度或单色后仍保持清楚轮廓。
- 在深色、浅色和游戏复杂背景上均能识别。
- 与 BiaoGe、BGLite、《魔兽世界》及其他插件现有图标没有可混淆的轮廓或素材。
- 图形路径保持精简，不嵌入字体、位图、第三方素材或隐藏元数据。

## 交付文件

- 1024 像素插件平台 PNG 主文件。
- 256、64、32 和 28 像素 PNG。
- 适合游戏加载的 TGA 版本。

当前图标由 BGNext 项目独立生成和整理，不包含 BiaoGe、BGLite、《魔兽世界》或其他插件素材。
