# BGNext 0.3.0

本次更新重点完善装备过滤、小地图交互、交易状态与鼠标提示性能。

## 装备过滤

- 内置方案可按当前客户端家族与当前专精／天赋树选择对应默认规则。玩家手动选择或修改的自定义方案不会被自动覆盖。
- 默认规则按版本处理武器、护甲、主属性及实际存在的词缀。旧版本猎人仍保留可作为属性武器的敏捷长柄、法杖和拳套等类型。
- 修复非正式服装备主属性判断；优先使用暴雪物品属性接口，接口不可用时回退本地 Tooltip。未知或尚未加载的装备保守放行。
- 旧天赋树客户端使用可辨识的方形天赋技能图标，并安全更新早期测试包保存的职业占位图或天赋页背景。

## 界面、姓名与交易

- 鼠标悬停小地图按钮约 0.2 秒后可预览角色总览；已固定的总览窗口不会因离开按钮而关闭。
- 修复小地图右键菜单点击外部后无法关闭，以及部分客户端提前创建按钮导致的 `SetFont` 报错。
- 非正式服的本服角色只显示角色名；正式服跨服角色继续保留服务器信息。界面缩短姓名不改变交易、欠款、退款、对账和拍卖记录内部身份。
- 修复装备已交付后仍留在“已拍未交易”列表的问题，支持同一物品一次交付多件。

## 性能

- 移除团队中每两秒执行的欠款／罚款全表扫描，改为需要显示 Tooltip 时按需构建缓存。
- 鼠标悬停装备时复用高亮 Frame、动画和数量文字；背包与当前表格用可失效索引查找对应物品。

## 数据与兼容边界

- 新增的装备过滤方案仅保存在当前角色本地的 `BiaoGe.BGNext.equipmentFilters`；不保存天赋历史，不读取其他玩家专精。
- 本版本不新增插件通信协议、游戏外传输或遥测。
- 已在时光服／Titan 客户端对组合测试包进行实机冒烟；其他客户端家族仍仅有自动测试或模拟证据。
- 全版本、全专精默认方案仍将在后续 Issue #37 中进行更完整的实机复核。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`，可以直接覆盖现有 `BGNext` 文件夹。

如果仍保留早期的 `Interface\AddOns\BGLite` 文件夹，请先删除旧插件文件夹，避免两个版本同时加载。不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。
