# BGNext 0.8.9 发布审计

## 变更范围

- 修复泰坦重铸 P5 双本分段清理未更新金币基准的问题。
- 为确实由多个副本共用的表格新增明确的整阶段清理入口。
- 整阶段清理复用既有整表清理路径，不新增第二套删除逻辑；支出继续遵守现有保留设置。
- 普通单本和只清当前副本的范围不扩大。

## 上游行为核对

- 原版 BiaoGe 2.3.5 与 BGLite 的新进度自动清理均使用整表清理，不会遗留共享杂项和旧金额。
- BGNext 保留后来增加的分段清理能力，同时用显式按钮提供原版整表清理语义，避免静默删除另一边副本。
- 未复制或重新打包 BiaoGe/BGLite 源码或素材。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方 BGLite 2.4.2 基线完整性和差异检查全部通过。
- 确认 P5 双本显示整阶段按钮，普通单本不显示。
- 确认局部清理只清当前范围并更新金币基准；整阶段清理只调用一次既有整表入口。
- 发布包只有一层 `BGNext/`，包含 `BGNext/BGNext.toc`，且所有 ZIP 条目使用 `/`。
- GitHub、新手盒子与网易 DD 的版本和更新日志统一为 0.8.9。

## 数据与兼容

- 不新增 SavedVariables 字段，不迁移现有数据，不修改通信协议、频道、接收人或权限。
- 整阶段清理会清除共享杂项、罚款、拍卖记录和当前团结算；支出按现有清表设置处理。
