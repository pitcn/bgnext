## 插件简介

BGNext 是基于官方 BGLite 纯净版 2.4.2 独立维护的金团表格插件，保留熟悉的账单、拍卖和分金流程，并加入价格预设、待拍队列、交易与邮件核对、三级心愿、结算前检查和自己的角色总览。

- 团长可保存多套起拍价、快速开拍、整理待拍装备并检查结算遗漏。
- 团员可设置个人心理价，用“备选 / 次 BIS / BIS”整理心愿装备。
- 完整、基础和自定义模式可自由选择，不想用的增强功能可以关闭。
- 数据主要保存在本地，不自动上传，也不建立其他玩家的跨团历史。
- 项目相关收入在依法处理必要税费后全部用于慈善，并公开可核验记录。

输入 /bgn 或 /bgnext 打开。界面支持简中、繁中，其他语言客户端回落英文。
