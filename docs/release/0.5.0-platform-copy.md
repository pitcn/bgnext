## 插件介绍

BGNext 是为金团记账、拍卖和结算准备的非官方社区插件。保留熟悉的高密度账单布局，把团长常用的价格方案、交易核对，以及团员自己的心愿和角色信息放在一起。

**团长常用**

- 按团本保存多套起拍价方案，设置基础价及单件价格。
- 表格装备 Alt+右键按预设开拍，Ctrl+右键修改单件价。
- 查看团队拍卖就绪状态，整理账单、欠款和当前团交易记录。
- 结算前集中检查漏填信息及待核对交易，不替代最终人工核账。

**团员常用**

- 保存个人心理价，出价仍由自己确认。
- 按首领整理心愿，用备选、次 BIS、BIS 区分需求，滚轮即可切换。
- 使用装备过滤及自己的角色总览，查看本人登录过的角色信息。

输入 /bgn 或 /bgnext 打开。提供简中、繁中，其他客户端语言回落英文；各游戏版本实际可用范围以发布说明为准。

BGNext 基于 BGLite 2.4.0 独立维护，不是暴雪、网易或上游官方产品。个人工具数据保存在本地，不自动向游戏外上传；当前团交易与邮件核对最多保留七天，不建立其他玩家历史档案。

安装时只需 BGNext 文件夹，无需 BGLite_KZ 等扩展。请勿同时启用 BGLite、BiaoGe 或依赖它们的扩展。更新前备份 WTF，替换插件目录时不要删除保存的设置。
