## 简要更新日志

BGNext 0.6.0

- 新增团长待拍队列，装备可排序并逐件确认开拍，不会自动连拍。
- 修复底栏按钮重叠和待拍窗口无法直接关闭，统一按钮外观。
- 拍卖结束后显示最终买家和成交金额，流拍、取消也有明确状态。
- 修复交易漏记、同物品多件数量、交易通报和“已交易 / 待核对”状态显示。
- 价格预设快捷开拍增加安全检查，价格列表会随窗口自动调整。
- 修复 Ctrl+右键改价、Alt+右键开拍时误删表格装备。
- 有未结算内容时，进新进度自动清表前会先确认。
- 正式服角色总览按 Boss 和难度统计团本进度。

支持经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服；部分新功能仍需各客户端实机验证，巫妖王与大地的裂变仍在适配，探索赛季不提供角色总览。

更新前请备份 WTF 并完整替换 BGNext 文件夹，不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。插件不自动向游戏外上传个人数据，当前团核对记录最多保留七天。

## 插件简介

BGNext 是基于 BGLite 2.4.0 独立维护的金团表格插件，保留熟悉的高密度账单，同时加入价格预设、待拍队列、拍卖结果、交易与邮件核对、三级心愿、结算前检查和自己的角色总览。

- 团长：多套起拍价方案、快捷开拍、待拍队列、账单与结算检查。
- 团员：个人心理价、备选 / 次 BIS / BIS 三级心愿、装备过滤和角色总览。
- 隐私：个人工具数据保存在本地，不自动上传，不建立其他玩家的跨团历史。
- 公益：项目相关收入在依法处理必要税费后全部用于慈善，并公开可核验记录。

输入 `/bgn` 或 `/bgnext` 打开。界面提供简中、繁中，其他语言客户端回落英文。
