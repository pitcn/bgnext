# BGNext 0.8.6

本版本为角色总览加入本地自定义角色顺序。

- 在“设置 → 角色总览”中可用“上移”“下移”调整角色行顺序。
- 顺序按客户端版本族分别保存；新角色仍按原有默认规则追加。
- “恢复默认排序”只清除当前客户端版本的自定义顺序，不删除角色快照或其他角色数据。
- 损坏、过期或重复的排序记录会被安全忽略，避免 Lua 报错、重复行或角色行缺失。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。

角色总览的周年时光服、经典永久 60、周年服 TBC、熊猫人和正式服均保持代码覆盖与自动化测试状态，尚待各客户端实机验证；探索赛季不提供角色总览入口。详情见[兼容性矩阵](../compatibility.md)。
