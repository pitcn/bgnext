# BGNext 0.8.7 发布审计

## 变更范围

- 发布基线：官方 BGLite 纯净版 2.4.2，固定 commit `5649f58`，186 个文件。
- 泰坦重铸装备等级解析优先使用当前客户端的详细装等接口，缺失或异常时回退到原有装等值。
- 表格、拾取、拍卖、交易与流拍通报共用同一解析结果；不修改装备分类、拍卖协议或物品归属逻辑。
- 修复当前团结算证据、相同成交匹配、拍卖消息发送者和心愿导入边界。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方基线完整性、diff 检查和发布包审计必须全部通过。
- 装等测试覆盖新接口、旧接口、接口异常、缓存回退、非装备物品和各主要展示/保存入口。
- 结算、消息发送者和心愿导入回归必须与原有拍卖、交易、心愿及当前团流程一起通过。
- ZIP、游戏内版本、Git 标签、GitHub Release、新手盒子和网易 DD 的版本及更新日志统一为 0.8.7。
- 发布包不得包含测试、Debug Tool、平台登录信息、发布计划、仓库治理文档或停用历史模块。

## 数据、来源与兼容

- 本次不新增 SavedVariables 字段，不扩大记录范围、接收人或游戏外传输。
- 装等实现依据对应客户端可用 API，并保留旧客户端兼容回退；未导入、复制、转换或重新打包第三方源码或资源。
- 泰坦重铸异常装备仍需游戏内确认具体显示；该限制不改变其他客户端的原有装等读取路径。
