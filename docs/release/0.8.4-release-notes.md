# BGNext 0.8.4

本版本集中修复 0.7.0 至 0.8.3 暴露出的基础拍卖、交易记账、快捷键、装备过滤和当前团对账回归。

- 修复拍卖成交已经写入买家和金额后，交易完成仍可能漏记欠款、错行或导致总消费不准确的问题。
- 恢复表格装备组合快捷键的原版优先级；新增的心愿和价格操作不再拦截 Shift 插入链接或交换单元格。
- 拍卖装备过滤恢复同步判断，避免法系、近战等筛选启用后仍显示全部装备。
- 团队刚建立或拾取职责变化时，按实时团队职责确认拍卖控制消息，避免第一条合法开拍、取消或计时消息被忽略。
- 对账期间普通成员变化不再直接清空结果；离团、账单来源离队或直接换团时仍会停止并清空本次临时采集。
- 修复旧版本或局部损坏的保存数据类型可能导致登录、开始当前团时报错的问题。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿和价格方案不需要重建。

BGNext 继续基于官方 BGLite 纯净版 2.4.2，并保持 BGLite 2.4.0 基础拍卖协议兼容。发布包继续登记经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服客户端；每个客户端的实际结果以对应版本实机测试记录为准。
