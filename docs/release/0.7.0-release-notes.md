# BGNext 0.7.0

本次更新主要让 BGNext 更容易按需使用，同时继续修复团队拍卖、交易记录和结算核对中的实际问题。

- 新增“完整 / 基础 / 自定义”三种增强模式。只想使用基础表格的玩家可以关闭大部分增强功能；以后切回时原有数据仍会保留。
- 新增游戏内说明书，集中查看功能介绍、快捷键、命令、权限要求、危险操作与隐私说明。
- 重做待拍队列窗口：布局更紧凑，关闭窗口不会误清队列，清空会单独确认，并能随窗口尺寸自动调整。
- 团长或有拾取职责的玩家可从 Boss 拾取窗口进入拍卖；所有入口统一检查权限、战斗状态、当前拍卖和价格。
- 修复预设 Alt+右键开拍、混合 BGNext/BGLite 团队同物品计时、拍卖卡片隐藏，以及结束后买家和成交金额不显示的问题。
- 修复部分成功交易、邮件和同物品记录遗漏；未知金额不会显示成伪造的 0，交易与核对状态仍分开呈现。
- 当前团账单可标记“退货待处理”，并在结算前提醒人工改价或退款；插件不会自动退款或覆盖原记录。
- 熊猫人角色总览新增天神首胜、农场收菜、四天神、斡耳朵斯四个可选项目，默认关闭；证据不足时显示未知。
- 上游基础更新至官方 BGLite 纯净版 2.4.2。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿和价格方案不需要重建。

插件登记覆盖经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服。不同客户端的新功能实测程度不同；巫妖王与大地的裂变仍在适配，探索赛季不提供角色总览。熊猫人新增追踪项目目前有代码与自动化覆盖，仍需当前国服客户端实机确认。

## 隐私与已知限制

本版本不自动向游戏外上传数据，不建立其他玩家的跨团历史。当前团交易和邮件核对最多保留最近一团、最长七天；基础/完整/自定义模式切换不会删除保存数据。

真实团队中的权限变化、Boss 拾取窗口、复杂多件交易、混合客户端拍卖，以及熊猫人活动状态仍需要游戏内验收。结算检查与退货标记只作提醒，最终金额和交付请人工核对。
