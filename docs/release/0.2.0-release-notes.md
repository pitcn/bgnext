# BGNext 0.2.0

BGNext 0.2.0 统一了插件名称和安装目录，并加入入口操作、聊天复制和拍卖安全方面的改进。

## 本次更新

- 换用新的 BGNext 图标。
- 插件安装目录由 `BGLite` 更名为 `BGNext`。
- 小地图按钮可以打开金团表格、角色总览和设置，角色总览快捷键恢复可用。
- 当前可见聊天消息中的 YY 号码可以由玩家手动点击复制，包括普通密语和战网密语。
- 加强拍卖金额校验及出价、欢呼消息限流。
- 对账数据只在当前游戏会话中使用，不再保存其他玩家的历史账单。

## 升级方法

从旧版本升级时，请先删除：

`World of Warcraft\_对应客户端_\Interface\AddOns\BGLite`

然后把新包中的 `BGNext` 文件夹安装到 `Interface\AddOns`。

请不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。BGNext 继续使用原有本地存档名称，旧设置和本地数据不会因为安装目录改名而主动清除。

## 数据与兼容性

- 当前团队拍卖继续兼容 BGLite 用户。
- YY 复制只处理玩家当前能看到的聊天消息，不保存聊天历史，不自动复制或发送。
- 拍卖及对账安全限制使用内存状态，不建立其他玩家的历史记录。
- 插件不包含遥测或游戏外自动同步。

## 下载校验

发布页同时提供 `BGNext-0.2.0.zip.sha256`。安装包内的插件目录应为 `BGNext/`，并包含 `BGNext/BGNext.toc`。
