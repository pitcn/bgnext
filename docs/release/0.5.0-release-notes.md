# BGNext 0.5.0

本次重点改善心愿优先级、价格预设和日常刷新性能，并加入当前团结算前检查。

- 心愿新增“备选 < 次 BIS < BIS”三档。新选装备默认备选，滚轮切换；独立文字徽标更易辨认，不占装备名称和装等的位置。已有优先级保持不变。
- 修复价格输入后点空白未保存的问题；团长在表格装备上 Alt+右键按预设开拍，Ctrl+右键修改单件价。旧价格和心愿字符串仍可导入。
- 同时拍卖相同装备时，收到有效出价后同步刷新截止时间。
- 减少角色总览和背包变化时的重复刷新；结算检查不再每秒扫描账单。
- 新增当前团结算前检查，集中提示欠款、账单缺项和待核对交易；证据不足时保留待确认，不自动当作已结清。
- 新增“存储与隐私”手动清理入口，并修复设置页文字报错。旧历史数据只有二次确认后才删除，升级和重载不会自动清理。
- 更新游戏内说明书、更新日志、插件介绍及简中、繁中、英文回落文案。

## 更新提醒

退出游戏并备份 WTF，再替换 AddOns 中的 BGNext 文件夹。不要同时启用 BGLite、BiaoGe 或依赖它们的扩展；BGNext 不需要 BGLite_KZ。已有心愿与方案不用重建。未标注优先级的旧心愿继续按次 BIS 读取，新选择才默认备选。

旧历史清理不可撤销，不要求为升级执行清理。当前团交易和邮件核对只保留最近一团，最长七天；个人工具只在本地使用。

## 验证范围与已知限制

玩家已反馈价格保存、旧字符串导入预览、心愿滚轮和重载保留正常，并反馈性能体感改善；这不是量化性能基准。最新默认备选和徽标布局有自动化覆盖。维护者决定不再增加发布前人工测试轮次；真实团队的相同装备计时、复杂交易/欠款联动，以及各客户端布局尚未完成全面实测。结算检查仅作辅助，最终金额及交付仍需玩家核对。

正式服部分掉落资料、团本 CD 与跨服团长识别仍有后续工作；本版不宣称全客户端、全团本均已验证。具体范围见仓库兼容性矩阵。
