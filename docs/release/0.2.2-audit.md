# BGNext 0.2.2 发布审计

## 范围

- 修复共享拍卖协议对 `GetTime()` 小数拍卖编号的误拦截。
- 所有拍卖发起入口固定使用第一代常规兼容协议。
- 删除协议代际、单一拍卖模式和重置阈值控件。
- 修复小地图菜单再次右键关闭。
- 隐藏货币 API 返回的无效周上限零值。
- 第二代接收器、自动出价主体、SavedVariables 格式和隐私边界保持不变。

## 发布门禁

- Lua 测试、Lua 语法、基线完整性、差异格式和发布包构建均须通过。
- 发布包根目录必须为 `BGNext/`，不得包含隔离的历史记录和旧整表接收源码。
- GitHub PR 检查全部通过后才能合并和创建 `v0.2.2` Release。
- 共享代码路径的自动测试通过不等同于每个客户端均已完成实机验证，发布说明必须保留该边界。
