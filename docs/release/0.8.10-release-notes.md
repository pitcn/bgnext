# BGNext 0.8.10

本版本修复未实际交易的拍卖提前写入账单，并让角色总览默认只显示满级角色。

- 团长或物品分配者结束拍卖后，只有真实交易完成才会把买家和金额写入主表，避免取消交易或买家反悔后产生错误账目。
- 普通团员仍可看到本地拍卖结果，不影响拍卖卡片、欠款选择及后续真实交易记账。
- 角色总览默认隐藏非满级角色，可在“设置 → 角色总览”勾选“显示非满级角色”恢复全部角色。
- 隐藏只影响界面显示，不删除角色数据、排序或采集记录；不同游戏版本继续使用各自的满级阈值。

## 安装

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。
