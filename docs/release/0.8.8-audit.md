# BGNext 0.8.8 发布审计

## 变更范围

- 修复 Windows `Compress-Archive` 生成反斜杠 ZIP 条目，导致部分发布或安装工具可能误判目录层级的问题。
- 构建器改为显式创建标准正斜杠 ZIP 条目；CI 直接拒绝任何反斜杠条目。
- 插件运行文件内容与 0.8.7 一致，仅版本元数据和游戏内更新说明变化。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方基线完整性和差异检查全部通过。
- 发布包只有一层 `BGNext/`，包含 `BGNext/BGNext.toc`，不含内嵌 ZIP。
- 所有 ZIP 条目使用 `/`，不得包含 `\`。
- 修正前后对应的 261 个插件文件内容逐项一致，仅版本元数据与更新说明除外。
- GitHub、新手盒子与网易 DD 的版本和更新日志统一为 0.8.8。

## 数据与兼容

- 不新增或迁移 SavedVariables，不修改通信协议、频道、接收人或权限。
- 不改变游戏内功能；本版本仅修正发布包格式和防回归检查。
