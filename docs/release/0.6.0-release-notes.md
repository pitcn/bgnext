# BGNext 0.6.0

本次重点修复真实团队中容易遗漏的拍卖结果、交易记录和交易通报，并加入团长待拍队列。

- 新增团长待拍队列：可以整理待拍装备、调整顺序并逐件确认价格后开拍；不会自动连续发送，离团、切换表格或重载后清空。
- 修复底栏按钮重叠，角色总览固定在最右侧；待拍窗口新增关闭按钮并统一外观。
- 拍卖倒计时结束后，侧边卡片会短暂显示最终买家和成交金额；流拍、取消也会明确显示。
- 交易确认时记录双方实际交付的物品、数量和金币；同物品多件不再因去重漏记。交易记录同时区分“已交易”和“待核对”，证据不足不会伪造为 0 或已结清。
- 修复交易成功/失败通报设置；同一交易最多发送一次，单纯关闭窗口不会误报。
- 价格预设快捷开拍增加统一的发送前检查；价格列表会随窗口和文字高度自动重排。
- 修复表格装备 Ctrl+右键、Alt+右键被误判为普通右键删除的问题。
- 上游基础升级到官方 BGLite 纯净版 2.4.1；拍卖聊天不再跨重载保存，并补充拍卖记录空数据容错。
- 进入新副本进度时，如果旧表仍有未结算内容，自动清空前会先确认，取消不会删除。
- 正式服角色总览按 Boss 和难度分别统计团本进度；部分击杀显示数量，API 证据不足时留空。

## 安装与兼容

退出游戏并备份 WTF，再完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿与价格方案不需要重建。

插件登记覆盖经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服；不同客户端的新功能实测程度并不相同。巫妖王与大地的裂变部分功能仍在适配，探索赛季不提供角色总览。准确状态以兼容性矩阵为准。

## 验证范围与已知限制

自动化已覆盖组合后的拍卖队列、结果展示、预设开拍门禁、交易采集/数量/通报、自动清空确认、价格列表布局和正式服团本进度。真实团队中的事件顺序、复杂多件交易、战斗中交易、权限临时变化以及各客户端 UI 仍需要游戏内验收；结算检查只作辅助，最终金额和交付请人工核对。

本版本不上传数据，不建立跨团玩家历史；待拍队列只存在内存中，当前团交易和邮件核对仍最多保留七天。
