# BGNext 0.8.10 发布审计

## 变更范围

- 恢复原版 BiaoGe/BGLite 的团长记账边界：拍卖结束只保留本地结果，真实交易完成后才写入主表。
- 保留 BGNext 的普通成员本地拍卖结果、团长本人欠款选择及现有交易记账流程。
- 角色总览新增“显示非满级角色”开关，默认关闭；过滤仅应用于显示投影。
- 满级判断使用各客户端现有的 `BG.fullLevel`，阈值缺失或无效时安全显示全部角色。

## 边界与兼容

- 不修改拍卖通信格式、消息权限、出价、重拍、流拍、退款或交易通报逻辑。
- 不删除或迁移角色快照，不改变角色排序、采集、专业冷却和副本进度数据。
- 不新增跨团历史或外部数据传输。
- 未复制或重新打包 BiaoGe/BGLite 源码或素材。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方 BGLite 2.4.2 基线完整性和差异检查全部通过。
- 验证团长、物品分配者和普通成员在拍卖结束、取消交易、真实交易及团长本人拍中时的分支。
- 验证默认过滤、设置开关、无效满级阈值和缺失角色等级的显示边界。
- 发布包只有一层 `BGNext/`，包含 `BGNext/BGNext.toc`，且所有 ZIP 条目使用 `/`。
- GitHub、新手盒子与网易 DD 的版本和更新日志统一为 0.8.10。
