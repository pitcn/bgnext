# BGNext 0.1.0 发布审计

状态：**发布候选，等待实机验收与平台审核**

## 代码与权利

- 开发基线固定为 BGLite 2.4.0，来源提交为 `9e0b119c66a644cce0083b5ffe4e59c6c946d0f1`。
- 上游 188 个文件由 SHA-256 清单核对；每个被 BGNext 修改的上游文件另行登记在覆盖清单中。
- `Core/BGNext/` 是新增功能边界。新增功能按项目规格和玩家可见需求独立实现，不读取、复制或改写历史 BiaoGe 源码与素材。
- BGLite 上游代码、素材和第三方库不声明为 BGNext 原创，权利说明见 `COPYRIGHT.md`。
- 仓库中的实现记录和测试说明保留真实工程语义，不用批量改写注释掩盖来源。

## 数据与通信

- BGNext 新增持久化数据只写入 `BiaoGe.BGNext`，完整字段见 `docs/security/data-inventory.md`。
- 不上传、不遥测，不自动向游戏外同步数据。
- 旧整表接收、跨团交易历史和跨团邮件历史不进入运行加载图或发布包。
- 拍卖控制消息只接受当前团长或主拾取者；版本查询只响应当前团队成员，并有发送者冷却与全局限流。
- 上述限流和自动出价状态只保存在内存中，重载后清除。

## 性能检查

- 角色总览只在窗口可见时启动 60 秒刷新计时器，隐藏后立即取消。
- 装备、背包等连续事件合并为一次延迟采集，避免事件风暴重复写入快照。
- 表格刷新复用文字、纹理和按钮对象，不在每次刷新时无限创建界面控件。
- 悬停摘要的 0.1 秒状态检查只在未固定的预览窗口可见时运行。
- 未在没有游戏内性能证据的情况下改动 BGLite 既有动画和拍卖计时路径，避免首版引入兼容性回归。

## 发布包

- 使用 `tools/build-release.ps1` 生成 ZIP；禁止直接压缩仓库或源码目录。
- 构建器从 `BGLite.toc` 和嵌套 XML 加载图解析运行文件，并加入所需媒体和权利声明。
- CI 会再次检查 ZIP 根目录和隔离文件，成功后上传可复核的构建产物。

## 发布前仍需人工确认

- 周年时光服：登录、重载、主窗口、心愿清单、角色总览、拍卖、自动出价、交易与邮件核对。
- 混用团队：BGNext 团长/BGLite 团员，以及 BGLite 团长/BGNext 团员的开始、出价、暂停、恢复、取消和结束。
- 永久 60、周年 TBC、熊猫人、正式服：按 `docs/compatibility.md` 核对入口、团本、货币和专业；未验证项目不得宣传为已支持。
- 正式服单 Boss 团本进度仍由 Issue #2 跟踪，不在 0.1.0 中宣称完成。
