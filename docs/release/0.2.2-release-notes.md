# BGNext 0.2.2

本次更新重点修复团队拍卖兼容问题，并简化拍卖发起窗口。

## 修复与调整

- 修复部分客户端无法开始拍卖或继续出价的问题。问题来自共享拍卖编号校验，因此永久60、周年TBC、周年时光服、熊猫人和正式服使用同一修复。
- 拍卖窗口不再显示“第一代/第二代”和只有一个选项的“常规模式”，也不再显示第二代专属重置阈值。
- 发起拍卖固定使用兼容旧插件的第一代常规协议，避免团员因插件版本不同而看不到拍卖；不会同时发送两代消息。
- BGNext 仍可接收其他兼容插件发来的第二代拍卖，并保留自动出价保护、金额校验、权限校验等本地优化。
- 小地图入口菜单现在可以再次右键关闭。
- 货币接口返回无效的周上限 `0` 时不再显示错误数字；只有客户端提供真实正数时才显示周上限。

以上拍卖与小地图修复位于所有支持客户端共用的代码路径。熊猫人已有问题报告作为本次修复依据，其他客户端仍欢迎继续反馈实机结果。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`，可以直接覆盖现有 `BGNext` 文件夹。

如果仍保留早期的 `Interface\AddOns\BGLite` 文件夹，请先删除旧插件文件夹，避免两个版本同时加载。不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。
