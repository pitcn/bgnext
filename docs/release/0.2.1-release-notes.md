# BGNext 0.2.1

BGNext 0.2.1 是针对 0.2.0 的启动热修复。

## 修复

- 修复打开插件或设置页时仍访问已停用的旧接收窗口而产生的报错。
- 修复简体中文客户端初始化临时对账按钮时产生的报错。

除上述修复外，功能、存档格式和隐私边界与 0.2.0 保持一致。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`。可以直接覆盖 0.2.0 的 `BGNext` 文件夹。

如果从 0.1.0 或更早版本升级，请先删除旧的 `Interface\AddOns\BGLite` 文件夹，但不要删除 `WTF` 或 SavedVariables 中的 `BiaoGe.lua`。
