# BGNext 0.8.13

- 角色总览新增独立缩放：设置 → 角色总览，可调50%–150%，保存选择并恢复默认；固定窗口与悬停预览同步生效，超出屏幕时自动限制大小。
- 奥杜尔等单本的新进度确认框新增“清空表格”，可一并清理杂项、罚款和当前团结算；支出遵循原有保留设置。
- 保留“只清当前副本”的Boss区间清理和双本表格的分段/整阶段选择；角色总览缩放不改变账单和拍卖窗口比例。

安装时解压为 `Interface/AddOns/BGNext/`，保留已有 SavedVariables。与旧版 BGLite 同时启用可能发生功能冲突，请按插件内冲突提示处理。

验证说明：107项自动测试、Lua 5.1语法、基线与发布包一致性检查通过。本次未新增客户端兼容声明；实际游戏字体、拖动、弹窗布局、已有存档加载与混合团队仍需实机验证。
