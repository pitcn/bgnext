# BGNext 0.4.0

本次更新加入团长起拍价与个人心理价预设、团队拍卖就绪检查，以及可切换的现代预览外观，同时保持原版账单布局、半透明背景和一张图截图习惯。

## 价格预设

- 团长可按团本保存多套命名起拍价方案，包含基础价和单件覆盖价；可新建、复制、重命名、删除、切换和导入导出。
- 团员可为自己的角色保存单件心理价，按角色、客户端、服务器和团本隔离。
- 打开现有拍卖或出价窗口时自动预填已保存价格，团长和团员仍需手动确认开始或出价。
- 多件装备价格不一致或无法安全解析时不预填，保持原值。
- 价格预设只保存在当前玩家本地；不自动开拍、不自动出价、不新增插件通信或游戏外传输。

## 团队拍卖就绪检查

- 进入团队后底部显示“团队拍卖：已就绪 X/Y”，不再显示容易误解的公会插件统计。
- 悬停可逐人查看状态：已就绪、插件已响应但拍卖端未响应、未响应、离线。
- “未响应”只代表尚未收到回复，不代表确定未安装。
- 团长或主拾取者点击可手动重新检测，请求有限流；检测结果不影响发起拍卖。
- 只复用现有团队版本消息，不新增消息格式、接收对象或成员历史记录。

## 界面现代化（预览外观）

- 新增可切换的 BGNext 预览外观，保持原版账单布局、半透明背景、行列容量和一张图截图习惯。
- 经典外观仍为默认；可在设置“外观预览”中随时切换，立即生效、随时切回。
- 预览主题对账单、价格预设页和部分高频页面统一品牌颜色、字号与控件状态。
- 价格预设页改为高密度双列展示，充分利用窗口空间。
- 移除装饰性 Boss 模型，减少视觉干扰；调整字号与颜色提升可读性。

## 数据与兼容边界

- 新增数据仅保存在 `BiaoGe.BGNext` 本地：团长起拍价方案、个人心理价和主题偏好；团队就绪状态仅保存在内存中，不写入存档。
- 本版本不新增插件消息、聊天发送、游戏外传输或遥测。
- Lua 自动测试、Lua 5.1 语法和基线完整性已经验证；上述新界面与功能尚未完成各客户端游戏内验证，不宣称所有客户端均已实机验证。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`，可以直接覆盖现有 `BGNext` 文件夹。

如果仍保留早期的 `Interface\AddOns\BGLite` 文件夹，请先删除旧插件文件夹，避免两个版本同时加载。不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。
