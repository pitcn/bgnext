# BGNext 0.8.2

这是一次紧急稳定性修复版本，处理自动拍卖已经产生成功记录、但主表买家和成交金额仍为空的问题。

- 成交结果现在会立即填写到下一条物品相同、买家与金额均为空的装备行。
- 已有手动填写和交易记账内容不会被覆盖。
- 修复团长权限发生变化时可能漏写结果的问题。
- 团长本人拍中时仍保留原有的“已付／欠款／不处理”选择，不会擅自记账。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿和价格方案不需要重建。

BGNext 继续基于官方 BGLite 纯净版 2.4.2，兼容协议保持 2.4.0。插件登记覆盖经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服；不同客户端的新功能实测程度不同，具体以兼容性文档为准。

## 已知限制

本版本已通过自动化回归、真实拍卖结束入口测试、基线完整性、Lua 语法和发布包结构检查。由于发布前无法进行真实团队实机验证，复杂团队权限变化、跨服拍卖和同物品多件连续拍卖仍建议在实际团队中继续观察。
