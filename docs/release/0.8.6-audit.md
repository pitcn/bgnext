# BGNext 0.8.6 发布审计

## 变更范围

- 发布基线：官方 BGLite 纯净版 2.4.2，固定 commit `5649f58`，186 个文件。
- 本版本发布角色总览的本地角色顺序：设置页可上移、下移，顺序按客户端版本族分别保存。
- 恢复默认排序只删除当前客户端版本的 `roleOverviewCharacterOrder`，不删除角色快照或其他角色数据。
- 损坏、过期或重复排序数据由现有校验读取路径安全忽略，避免 Lua 报错、重复行或角色行缺失。
- 不修改拍卖、交易、通信协议、频道、接收人、上游 `Version` 2.4.2 或其他运行时行为。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方基线完整性、diff 检查和发布包审计必须全部通过。
- 角色顺序测试覆盖版本族隔离、恢复默认不删除角色快照，以及损坏、过期和重复记录的安全回退。
- ZIP、游戏内版本、Git 标签、GitHub Release、新手盒子和网易 DD 的版本及更新日志统一为 0.8.6。
- 发布包不得包含测试、Debug Tool、平台登录信息、发布计划、仓库治理文档或停用历史模块。

## 数据、来源与兼容

- 本次没有新增字段：`roleOverviewCharacterOrder[clientFamily][*]` 已在数据清单中记录为仅保存本地自身角色 `realmId` 和 `player` 的低风险排序数据；无接收人、无通信、无游戏外传输。
- 行为来自 BGNext 自有角色总览模块与测试；未导入、复制、转换或重新打包 BiaoGe/BGLite 以外的第三方源码或资源。
- 角色总览的周年时光服、经典永久 60、周年服 TBC、熊猫人和正式服只声明代码覆盖与自动化测试，尚未声明实机支持；探索赛季明确不加载该入口。
