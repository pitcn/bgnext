## 安装迁移

升级用户需要手动删除旧的 `Interface\AddOns\BGLite` 文件夹，再安装新的 `BGNext` 文件夹。不得删除 `WTF` 或 SavedVariables 中的 `BiaoGe.lua`。BGNext 不会自动操作玩家的插件目录。

## 仍需观察

自动测试不能替代游戏内验证。发布后重点观察：

- 小地图菜单、左右键和角色总览快捷键在各客户端的实际表现；
- 普通密语与战网密语中的 YY 手动复制入口；
- 正常团队拍卖、出价、欢呼和对账流程是否维持兼容；
- 从旧目录升级后是否仍有插件管理器保留重复目录。

这些项目不改变当前隐私边界；发现回归时应停止分发并按对应 PR 范围修复。
