# BGNext 0.8.1

这是一次稳定性修复版本，重点处理玩家反馈的键盘失效、角色总览误报、拍卖卡片展开和团长工具布局问题，并继续加固核心记账流程。

- 修复部分 BGNext 输入窗口关闭后仍占用键盘焦点，导致移动、聊天或其他按键暂时失效的问题。插件不会修改玩家的按键绑定。
- 修复角色总览把未学习专业的配方错误显示为已就绪的问题。旧角色数据会在该角色再次登录后自动刷新。
- 拍卖卡片折叠后不再在倒数结束时强制展开；折叠摘要仍会显示买家和成交金额。
- 调整团长工具在不同界面缩放下的布局，减少按钮重叠、内容越界和关闭按钮不可见。
- 加固跨服拍卖权限、交易与批量邮件核对，以及相同物品和延迟事件下的结算处理。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿和价格方案不需要重建。

BGNext 继续基于官方 BGLite 纯净版 2.4.2，兼容协议保持 2.4.0。插件登记覆盖经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服；不同客户端的新功能实测程度不同，具体以兼容性文档为准。

## 已知限制

本版本已通过自动化回归、基线完整性、Lua 语法和发布包结构检查，但复杂团队权限变化、跨服拍卖、批量邮件、同物品多件交易及不同界面缩放仍建议在实际团队中继续观察。插件不会自动向游戏外上传个人数据，也不建立其他玩家的跨团历史。
