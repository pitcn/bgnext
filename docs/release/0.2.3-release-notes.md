# BGNext 0.2.3

本次更新修复正式服心愿清单与角色总览问题，并改进不同分辨率下的表格缩放。

## 修复与调整

- 正式服普通、英雄和史诗三种难度改为纵向排列，避免史诗难度区域超出窗口。
- 正式服自有角色总览优先使用插件初始化时已经确认的当前角色身份，避免受客户端受限接口影响而无法保存快照。
- 尚未适配掉落资料的正式服团本会显示明确提示，并保留手动拖入装备或 Shift 点击装备加入个人心愿的方式；本版本没有伪造或补写未知掉落数据。
- 表格会按屏幕可用宽高限制实际缩放，同时保留玩家设置的首选比例。切换表格、调整 UI 缩放或改变分辨率后会重新计算，窗口边缘被裁切时会回到屏幕中央。
- 新增隐藏兼容命令 `/biaoge`；它与 `/bgn` 共用同一入口，也支持 `/biaoge role` 打开自有角色总览。

## 数据与兼容边界

- 本次没有新增 SavedVariables 字段、游戏内消息或游戏外传输。
- 正式服身份修复只记录当前登录的本人角色，其他客户端继续使用原有读取路径。
- `/bgn` 和 `/bgnext` 仍是推荐命令；如果同时启用其他表格插件，`/biaoge` 可能由加载顺序决定归属。
- 自动测试覆盖五类客户端的共享代码路径，但缩放效果仍需要更多客户端、分辨率和窗口模式的实机反馈。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`，可以直接覆盖现有 `BGNext` 文件夹。

如果仍保留早期的 `Interface\AddOns\BGLite` 文件夹，请先删除旧插件文件夹，避免两个版本同时加载。不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。
