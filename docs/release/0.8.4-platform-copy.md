# 国内平台文案

以下内容可直接用于新手盒子或网易 DD；本文件不表示已经向平台上传。

## 简要更新日志

BGNext 0.8.4

- 修复成交已填写买家和金额后，交易完成仍可能漏记欠款、错行或算错总消费的问题。
- 恢复表格装备组合快捷键和装备过滤，避免新增操作拦截 Shift 组合或过滤开启后仍显示全部装备。
- 团队刚建立或拾取职责变化时使用实时权限判断，减少第一条合法拍卖消息被忽略。
- 对账不再因普通成员变化而消失；离团、来源离队或直接换团时仍会安全停止。
- 修复旧或损坏保存数据可能导致登录、开始当前团时报错的问题。

BGNext 继续基于官方 BGLite 纯净版 2.4.2。更新前请完全退出游戏、备份 WTF，并完整替换 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。
