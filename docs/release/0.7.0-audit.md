## 数据、安全与来源

- 上游基础为官方 BGLite 纯净版 2.4.2，来源快照与 BGNext 覆盖文件均由 SHA-256 清单保护。
- 功能模式仅改变功能是否启用，不自动删除账单、设置、心愿、价格方案或角色总览数据。
- 待拍队列继续只存在当前运行会话内存中，不新增跨重载队列历史，也不会自动连续开拍。
- 交易与邮件核对仍限制为当前团或最近一次未结算团本、最长七天；未知物品、数量或金币保持未知。
- 退货标记只保存当前团账单行的本地待处理状态，不自动退款、不改写买家与金额、不向外发送。
- 熊猫人活动只保存本人角色的有限状态摘要；农场拾取不保存聊天、坐标轨迹或其他玩家信息。
- 未加入遥测、游戏外上传、远程控制、其他玩家跨团档案或第三方排名。

## 发布门禁

- 完整 Lua 测试、基线完整性、Lua 语法、diff check、数据清单和发布包加载图检查必须全部通过。
- ZIP 只能有 BGNext/ 根目录，并包含版本为 0.7.0 的 BGNext/BGNext.toc；不得包含测试、工具、Git 文件或隔离的旧历史/整表接收模块。
- 本候选包不修改游戏目录、WTF、GitHub Release 或国内平台；完成实机验收后再创建正式标签和 Release。

## 待实机验证

- 完整/基础/自定义模式的可见功能、重载保留与数据不丢失。
- 待拍队列在关闭、清空确认、缩放和不同语言下的布局。
- Boss 拾取窗口真实类型、团长/拾取职责权限变化和战斗中门禁。
- 混合 BGNext/BGLite 团队中的同物品拍卖计时、结果展示及复杂交易事件顺序。
- 熊猫人客户端的 LFG 奖励、周常任务和日歌农场实际作物拾取 API。
