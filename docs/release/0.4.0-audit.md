# BGNext 0.4.0 发布审计

## 范围

- 价格预设：团长起拍价多方案与个人心理价，只预填现有输入框，不自动开拍或出价。
- 团队拍卖就绪检查：以拍卖端响应作为就绪依据，复用现有团队版本消息，不新增协议或成员历史。
- 界面现代化：可切换预览外观、账单视觉层级、共享控件与价格页双列；经典外观仍为默认。
- 移除装饰性 Boss 模型，调整字号与颜色可读性。

## 数据、安全与隐私

- 新增 `BiaoGe.BGNext.leaderAuctionPricePresets`、`BiaoGe.BGNext.personalAuctionExpectations` 与 `BiaoGe.BGNext.settings.uiTheme`，均只保存在本地，无接收方、无历史、无跨团聚合。
- 团队拍卖就绪状态仅保存在内存中，不写入 SavedVariables，不保存成员版本历史；复用现有团队版本消息与发送者校验，不新增消息字段或接收对象。
- 本版本不新增插件消息、聊天发送、接收对象、外部传输或遥测。
- 价格导入导出仅使用手动、可预览、可取消的复制粘贴文本，不调用剪贴板、HTTP、遥测或聊天接口。

## 来源与基线

- 本次未复制、翻译或打包第三方插件源码、配置、数据库、文案或素材；参考研究仅提取玩家可见行为与兼容需求，实现由 BGNext 独立编写（ADR-0003）。
- 修改的 BGLite 基线运行文件逐项登记到 `docs/baseline/BGNext-overrides.sha256`，原始 188 文件基线清单不变。
- 发布包继续由 `tools/build-release.ps1` 根据 TOC/XML 加载图生成，并排除历史记录、旧整表接收、测试、工具和开发文档。
