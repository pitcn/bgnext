# BGNext 0.2.3 发布审计

## 范围

- 合并 PR #16：正式服三难度心愿布局、自有角色身份读取和未适配掉落提示。
- 合并 PR #19：按屏幕空间约束主表格缩放，并响应 UI 缩放和分辨率变化。
- 合并 PR #20：增加隐藏的 `/biaoge` 兼容命令。

## 数据、安全与来源

- 没有新增或扩大 SavedVariables 字段、游戏内通信、接收对象或游戏外传输。
- 正式服角色总览只使用当前登录角色已经确认的本地身份；不读取或保存其他玩家资料。
- 正式服未知掉落仍标记为待适配，没有从历史 BiaoGe 源码或不明数据库复制数据。
- 缩放模块和兼容命令为 BGNext 独立实现；BGLite 2.4.0 基线改动继续逐文件登记哈希。

## 发布门禁

- Lua 测试、基线完整性、差异格式和发布包构建必须全部通过。
- 发布包根目录必须为 `BGNext/`，并排除历史记录、旧整表接收源码、测试和开发文档。
- 保存数据名称仍为 `BiaoGe`，没有迁移或清空玩家现有数据。
- 自动检查不等于五类客户端均完成实机验证；正式服掉落完整度和多分辨率缩放继续列为已知限制。
