# 国内平台文案

以下内容可直接用于新手盒子或网易 DD；本文件不表示已经向平台上传。

## 简要更新日志

BGNext 0.8.1

- 修复关闭部分插件窗口后键盘、移动或聊天按键暂时失效的问题；不会修改玩家按键绑定。
- 修复角色总览把未学习专业的配方错误显示为已就绪；旧数据会在该角色再次登录后刷新。
- 拍卖卡片折叠后保持折叠，结束时仍显示买家和成交金额。
- 优化团长工具在不同界面缩放下的布局，减少按钮重叠、内容越界和关闭按钮不可见。
- 加固跨服拍卖权限、交易与批量邮件核对，以及同物品和延迟事件下的结算处理。

BGNext 继续基于官方 BGLite 纯净版 2.4.2。更新前请完全退出游戏、备份 WTF，并完整替换 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。不同客户端和复杂团队场景仍建议继续观察，插件不会自动向游戏外上传个人数据。

## 插件简介

BGNext 是基于官方 BGLite 纯净版 2.4.2 独立维护的金团表格插件，保留熟悉的账单、拍卖和分金流程，并加入价格预设、待拍队列、交易与邮件核对、三级心愿、结算前检查和自己的角色总览。

输入 /bgn 或 /bgnext 打开。界面支持简中、繁中，其他语言客户端回落英文。
