## 数据、安全与来源

- 新选择显式写入已有的 backup 枚举；读取纯物品 ID、旧导入和旧平铺迁移仍保留 normal 含义。重新确认相同物品保留优先级，不重置现有数据。
- 无新增存储字段、协议字段、接收方或外部传输。数据范围见现有 data inventory；无跨团历史或其他玩家画像。
- 仅独立实现和既有批准资源；本轮未引用新的外部插件代码或资源。
- 本版收尾的基线变动仅 TOC 版本及三份 Locale 的玩家说明、介绍和更新文案，逐份审阅后更新对应四个显式哈希；原始基线不变。
- 保留上游/协议版本 2.4.0，不将产品版本 0.5.0 写入旧协议。

## 验证与限制

- Lua 测试覆盖新选默认备选、同装备保留、替换重置、导出导入、旧迁移及三语指南/日志。
- 发布前执行完整 Lua 套件、基线检查、diff check、包加载图检查及 ZIP 与源码逐项 SHA256 核对。精确发布提交和包摘要随 Release 及本地交接保存。
- 玩家已反馈价格保存、旧字符串预览、优先级切换和重载保留通过。性能改善为体感，不作为量化基准。
- 维护者明确结束 ready-for-human 人工测试等待；关闭相关 Issue 不意味着所有客户端或团队场景已实测。未完成的独立 Issue 保持开放。
- 新默认值和最新徽标由自动化覆盖；复杂团队交易、相同物品计时及各版本客户端 UI 未全面实测。不将缺少证据写成通过。
- 不操作游戏目录、WTF 或真实玩家数据。国内平台仅提供待粘贴文案，不自动发布。
