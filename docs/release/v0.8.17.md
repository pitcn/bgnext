# BGNext 0.8.17

- 首次在主线版本中加入无限服（Interface 16001）适配基础：团本目录（P0 黑石塔上层，P1 深穴、海加尔峰、奥妮克希亚）、角色总览的藏宝海湾周常、专业冷却和可配置货币列，以及背包、天赋、物品和提示框接口适配。P0 掉落仅为初始装备参考，P1 掉落暂为空。
- 修复无限服角色总览：完整识别带姓氏的角色名，避免不同角色混在一起；无法确定归属的旧单段角色记录会在加载时丢弃；已缓存的装备在物品信息暂缺时保留最后观察值，不再丢失栏位。
- 角色总览默认显示练级角色，新增“只看满级角色”开关；此前主动选择隐藏非满级角色的设置会保留，不会删除角色记录。
- 练级角色被过滤隐藏时，空列表会提示隐藏数量和取消勾选的位置，不再显示“没有本地角色记录”。
- 无限服新建拍卖价格方案的基础价改为 10g；已有方案价格不变。

本轮完成本机 Lua 自动测试、基线核对和空白检查。无限服已在游戏内验证：角色总览默认显示与满级筛选、空状态提示、两段名分开记录、旧单段残留清理、武器/饰品登录后仍显示，以及新建起拍方案默认基础价 10g。团本目录、周常/专业冷却/货币列，以及拾取、完整拍卖流程、清空和周锁尚未单独完成游戏内验收，不宣称无限服正式支持，详见 docs/compatibility.md；其他客户端的实机验证状态不变。

更新前退出游戏并备份 WTF，完整替换 BGNext 文件夹；避免同时启用 BGLite、BiaoGe 或依赖它们的扩展。
