# BGNext 0.8.17

这是 BGNext 的常规 0.8.17 更新，现有客户端按正常流程升级即可。同一个安装包同时首次加入对无限服（Forever，Interface 16001）的支持，无需另装其他版本。

- 无限服首次加入：团本目录包含 P0 黑石塔上层，以及 P1 深穴、海加尔峰、奥妮克希亚。P0 掉落仅为初始装备参考，P1 掉落暂时为空。角色总览新增藏宝海湾周常、专业冷却和可自行配置的货币列，并适配该客户端的背包、天赋、物品和提示框。
- 修复无限服角色总览：带姓氏的两段角色名现在会完整识别，不再被截短后混在一起；加载时会丢弃无法确定归属的旧单段角色记录；装备信息暂时读不到时，保留最后一次看到的装备，不再丢栏位。
- 默认设置变更（2026-11-16）：角色总览新增“只看满级角色”开关。仅无限服默认显示练级角色；其他客户端默认仍只显示满级角色，行为不变。你之前主动选择过的显示设置会继续生效，不会删除任何角色记录。
- 练级角色被“只看满级角色”隐藏时，空列表会说明隐藏了几个角色、在哪里取消勾选，不再误显示“没有本地角色记录”。
- 无限服新建的拍卖价格方案，基础价默认改为 10g；已有方案的价格保持不变，全局拍卖价也不改动。

本轮完成本机 Lua 自动测试、基线核对和空白检查。无限服已在游戏内验证：角色总览默认显示与满级筛选、空状态提示、两段角色名分开记录、旧单段记录清理、武器/饰品登录后仍显示，以及新建起拍方案默认基础价 10g。无限服的团本目录，周常、专业冷却和货币列，以及拾取、完整拍卖流程、清空和周锁尚未单独完成游戏内验收，因此不宣称无限服已正式支持；其他客户端的实机验证状态不变，详见 docs/compatibility.md。

更新前退出游戏并备份 WTF，完整替换 BGNext 文件夹；避免同时启用 BGLite、BiaoGe 或依赖它们的扩展。
