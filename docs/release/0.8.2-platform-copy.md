# 国内平台文案

以下内容可直接用于新手盒子或网易 DD；本文件不表示已经向平台上传。

## 简要更新日志

BGNext 0.8.2

- 紧急修复拍卖成功记录已经出现，但主表买家和成交金额仍为空的问题。
- 成交结果会立即填写到下一条匹配的空白装备行，不覆盖已有手填和交易记账内容。
- 修复团长权限变化时可能漏写的问题；团长本人拍中仍保留已付或欠款选择。

BGNext 继续基于官方 BGLite 纯净版 2.4.2。更新前请完全退出游戏、备份 WTF，并完整替换 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。复杂团队场景仍建议继续观察。

## 插件简介

BGNext 是基于官方 BGLite 纯净版 2.4.2 独立维护的金团表格插件，保留熟悉的账单、拍卖和分金流程，并加入价格预设、待拍队列、交易与邮件核对、三级心愿、结算前检查和自己的角色总览。

输入 /bgn 或 /bgnext 打开。界面支持简中、繁中，其他语言客户端回落英文。
