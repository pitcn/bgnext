# BGNext 0.8.3

这是一次基础拍卖、交易和键盘焦点的稳定性修复版本。

- 修复拖动拍卖窗口时出现 Lua 报错，以及关闭部分输入窗口后键盘仍被占用的问题；插件不会修改玩家按键绑定。
- 拍卖成功后先保存成交记录、主表买家与金额及团长账务，再刷新界面。物品缓存延迟或其他界面插件报错不再阻断核心记账。
- 修复交易对象短暂不可读时出现买家为空、金额或装备遗漏，以及错误沿用上一位交易对象的问题。
- 修复价格预设读取部分装备库数据时报错，并移除已经不存在的旧拍卖刷新调用。
- 团长或物品分配者在聊天框对装备按 Alt+左键时会打开拍卖窗口；普通团员仍可将装备加入个人心愿。
- 修复角色总览的专业冷却时间换算，并且只显示当前角色真正学会的配方。
- 更新日志窗口会按内容调整高度，减少文字显示不全。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿和价格方案无需重建。

BGNext 继续基于官方 BGLite 纯净版 2.4.2，并保持 BGLite 2.4.0 基础拍卖协议兼容。发布包登记适配经典永久 60、周年服 TBC、周年时光服、熊猫人和正式服当前版本。
