# BGNext 0.8.5

本版本修复交易通报设置在基础模式下可能失效的问题。

- 选择基础模式或完整模式，不再覆盖交易设置中的通报开关。
- 功能管理页不再显示第二个容易造成误解的交易通报总开关。
- 是否发送、发送成功或失败消息以及发送频道，仍完全按照原交易设置执行。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。已有账单、心愿、价格方案和交易通报设置不会被清空。

BGNext 继续基于官方 BGLite 纯净版 2.4.2，并保持现有 BGLite 拍卖协议兼容。本版本没有改变交易记账、欠款、拍卖消息、通知接收人或保存数据结构。
