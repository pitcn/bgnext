# BGNext 0.3.1

本次更新集中修复拍卖、记账和职业颜色问题，并为团长增加快速查看全部装备的入口。

## 拍卖与记账

- 修复在主表格装备格按住 Alt 并点击右键时无法直接发起拍卖的问题。
- 修复团长或物品分配者自己拍得装备时，角色名是否带服务器后缀不一致会导致记账提示不出现的问题。
- 最近一次拍卖的交易匹配和团长自交易状态现在使用统一的角色身份判断。

## 职业颜色

- 拍卖记录会从当前团队名单获取买家职业信息，不再因为角色名无法作为游戏单位读取而固定显示为白色。
- 从拍卖记录生成或回填账单时使用相同的职业颜色。
- 已有记录如果保存了有效职业信息，也会重新显示对应职业颜色；确实无法识别时仍安全使用白色。

## 装备过滤

- 专精和自定义方案旁新增深色红叉按钮，可一键临时关闭全部装备过滤并显示所有装备。
- 再次点击红叉会恢复原来的跟随专精或手动方案；直接选择任意方案也会重新启用过滤。
- 关闭过滤不会删除或改写已有方案。

## 数据与兼容边界

- 新增的 `enabled` 只保存当前角色是否临时启用装备过滤，不包含装备记录、专精历史或其他玩家资料。
- 本版本不新增插件消息、聊天发送、游戏外传输或遥测。
- Lua 自动测试、Lua 5.1 语法和基线完整性已经验证；上述新交互尚未完成各客户端游戏内验证，不宣称所有客户端均已实机验证。

## 安装

解压后，将 `BGNext` 文件夹放入对应客户端的 `Interface\AddOns`，可以直接覆盖现有 `BGNext` 文件夹。

如果仍保留早期的 `Interface\AddOns\BGLite` 文件夹，请先删除旧插件文件夹，避免两个版本同时加载。不要删除 `WTF` 文件夹或 SavedVariables 中的 `BiaoGe.lua`。
