# BGNext 0.8.5 发布审计

## 变更范围

- 发布基线：官方 BGLite 纯净版 2.4.2，固定 commit `5649f58`，186 个文件。
- 修复 0.7.0 功能模式引入的第二个交易通报总开关：功能管理仅声明通报能力可用，实际发送继续由原交易设置授权。
- 不修改交易记账、欠款、金额、拍卖流程、通信协议、频道、接收人或重复发送保护。
- 不新增 SavedVariables 字段；旧的 `settings.features.trade_announcement` 可选状态由现有设置清理逻辑移除，不改变 `tradeMSG` 和其他功能设置。
- 同批路线边界文档不进入运行包，也不作为玩家功能变更发布。

## 验证要求

- Lua 回归、Lua 5.1 语法、官方基线完整性和发布包审计必须全部通过。
- 通报组合测试覆盖功能模式、专用总开关、成功/失败子开关、频道、接收人和重复事件；功能模式不得主动开启或关闭专用总开关。
- ZIP、游戏内版本、Git 标签、GitHub Release、新手盒子和网易 DD 的版本及更新日志统一为 0.8.5。
- 发布包不得包含测试、Debug Tool、平台登录信息、发布计划、仓库治理文档或停用历史模块。

## 数据、来源与兼容

- 数据清单无新增类别、保存位置、接收对象或保留周期。
- 行为参考项目内固定的官方 BGLite 2.4.2 基线和原 BiaoGe 研究记录；本次实现为 BGNext 自有功能目录与测试调整，未引入第三方源码或资源。
- 本次不声明新增客户端实机支持；各客户端状态继续以 `docs/compatibility.md` 为准。
