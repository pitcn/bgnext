# BGNext 0.8.9

本版本修复泰坦重铸 P5 双本自动清表可能遗留共享区域与旧金额的问题。

- P5 双本的新进度确认框新增“清理所有 P5 副本”，可一次清理两边副本、共享杂项、罚款和当前团结算。
- “只清当前副本”继续保留另一边副本以及共享区域，避免误删仍需使用的记录。
- 分段清理会同步记录当前角色金币，修复清表金币显示灰色或沿用旧角色记录的问题。
- 整阶段按钮只在多个副本确实共用同一张表时出现，普通单本不会扩大清理范围。

## 安装

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。
