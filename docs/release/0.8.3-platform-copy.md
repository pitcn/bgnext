# 国内平台文案

以下内容可直接用于新手盒子或网易 DD；本文件不表示已经向平台上传。

## 简要更新日志

BGNext 0.8.3

- 修复拖动或关闭拍卖窗口时报错，以及部分窗口关闭后键盘仍被占用的问题。
- 拍卖成交现在先保存买家、金额和账务，再刷新界面；物品缓存延迟或界面插件报错不会阻断核心记账。
- 修复交易对象短暂不可读时买家为空、金额或装备遗漏，以及错误沿用上一位交易对象的问题。
- 修复专业冷却时间错误、价格预设装备库报错和旧拍卖刷新报错。
- 团长在聊天框 Alt+左键点击装备时恢复为打开拍卖窗口；更新日志窗口减少文字显示不全。

BGNext 继续基于官方 BGLite 纯净版 2.4.2。更新前请完全退出游戏、备份 WTF，并完整替换 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。
