## 数据、安全与来源

- 待拍队列只在当前运行会话内存中存在，不新增 SavedVariables；不会自动连续开拍。
- 交易采集仍限定当前团、最近一团且最长七天；未知物品、数量或金币保持未知，不伪造事实，不新增聊天正文或跨团玩家档案。
- 交易通报沿用玩家现有开关和游戏内频道，只在可靠终态发送一次，不持久化通报内容。
- 正式服团本进度只保存玩家本人角色的摘要；API 证据不足时留空。
- 本轮升级到活动渠道提供的官方 BGLite 纯净版 2.4.1 基线；完整上游快照单独留档，BGNext 覆盖逐文件登记。未引入其他插件代码、外部网络传输、遥测或游戏外上传。
- 官方 2.4.1 的拍卖聊天记录不持久化与拍卖记录空数据容错已纳入；新 CD 清表仍保留 BGNext 更严格的确认保护。

## 发布门禁

- 完整 Lua 测试、基线完整性、Lua 语法、diff check、数据清单和发布包加载图检查必须全部通过。
- ZIP 必须只有 `BGNext/` 根目录，包含版本为 0.6.0 的 `BGNext/BGNext.toc`，不包含旧 BGLite 包名、测试、工具、Git 文件或隔离的历史/接收模块。
- 本测试包不操作游戏目录、WTF、GitHub Release 或国内平台；玩家完成实机验收后再合并发布。

## 待实机验证

- 真实团队中交易确认事件顺序、战斗中交易、同物品多件交付与金币读取。
- 待拍队列及预设直拍在权限变化、进战斗、已有拍卖和真实掉落目录下的行为。
- 拍卖卡片成交/流拍/取消显示、价格列表缩放和三语 UI。
- 正式服真实团本锁定 API 返回形状与逐 Boss 提示。
