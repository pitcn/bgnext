# BGNext 0.8.7

本版本修复泰坦重铸装备等级显示，并收紧当前团结算、拍卖消息和心愿导入边界。

- 泰坦重铸部分装备现在读取客户端提供的有效物品等级；表格、拾取、拍卖、交易与流拍通报使用同一结果。
- 缺少新装等接口的客户端继续使用旧接口和缓存值，不改变原有装备记录流程。
- 当前团结算不再在金币证据不完整时过早判定；相同装备、相同金额但买家不同的记录不再混淆。
- 修复部分拍卖提醒、重拍与退款消息可能识别错发送者的问题。
- 心愿清单导入默认安全合并；选择替换时会先显示新增、覆盖和删除数量并再次确认。

## 安装与兼容

完全退出游戏并备份 WTF，然后完整替换 AddOns 中的 BGNext 文件夹；不要同时启用 BGLite、BiaoGe 或依赖它们的扩展。

泰坦重铸有效装等修复已按对应客户端 API 路径和自动化用例验证；具体异常装备仍建议在泰坦重铸客户端中确认显示结果。其他客户端保留兼容回退。
