# BGNext 0.3.0 发布审计

## 范围

- Issue #22：非正式服主属性检测与按客户端／专精生成的默认装备过滤方案。
- Issue #23：鼠标装备高亮对象复用与按需索引。
- Issue #24：移除固定周期的欠款全表扫描。
- Issue #27：显示姓名与内部规范身份分离，以及职业着色。
- Issue #28：小地图按钮悬停预览角色总览。
- Issue #29：装备交付后清理待交易拍卖记录。
- Issue #30：小地图右键菜单生命周期与字体初始化安全。

Issue #18 的正式服跨服团长问题不属于本版本。Issue #37 记录后续的全客户端、全专精默认配置完整复核。

## 数据、安全与隐私

- 新增 `BiaoGe.BGNext.equipmentFilters[realmId][player]`，仅保存当前角色的方案规则、顺序和选择模式。专精／天赋树只在运行时读取，不保存天赋点、历史或其他玩家数据。
- 本版本不新增 SavedVariables 根命名空间，不新增插件消息、聊天发送、接收对象、游戏外传输或遥测。
- 姓名缩短仅用于显示；交易、欠款、退款、对账和拍卖继续使用规范身份。
- 交易状态归并继续遵守当前结算范围、允许字段白名单和最长七天保留期。

## 来源与原创边界

- 按 ADR-0003 研究了本机合法安装的 BiaoGe、BGLite 和 WeakAuras，仅提取玩家可见行为、客户端 API 差异和方形可辨识图标这些需求。
- BGNext 的适配器、规则合成、状态模型、用户界面和测试独立编写。没有复制、翻译、改写或打包第三方源码、图标映射表、文本或资源。
- 旧天赋树图标由暴雪 `GetNumTalents` / `GetTalentInfo` 运行时返回，不包含第三方图标资产。

## 兼容性证据

- 维护者已在时光服／Titan 客户端对 v0.3.0 组合测试包完成实机冒烟，包括主属性过滤、专精方案、小地图菜单／角色总览、姓名显示与交易状态。专精图标仅达到可接受的冒烟程度，后续仍可优化视觉选择。
- 永久 60、TBC、熊猫人和正式服的相关路径仅有代码覆盖、自动测试或模拟证据，不宣称已完成实机验证。

## 发布门禁

- Lua 自动测试、Lua 5.1 语法、基线完整性、差异格式和发布包审计必须全部通过。
- BGLite 2.4.0 基线保持 188 个文件，BGNext 明确登记 30 个基线覆盖。
- 发布包必须从 TOC/XML 运行时加载图构建，根目录为 `BGNext/`，并排除历史记录、旧整表接收源码、测试、工具、研究和开发文档。
- 发布包中必须使用 `BGNext.toc`，不包含仓库开发用的 `BGLite.toc`。
