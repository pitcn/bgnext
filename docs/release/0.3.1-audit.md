# BGNext 0.3.1 发布审计

## 范围

- 修复主表格 Alt+右键无法发起拍卖。
- 修复团长自己中标时短名／带服务器名造成的自动记账与交易状态判断错误。
- 修复拍卖记录与账单回填的职业颜色来源。
- 为装备过滤增加保留原方案的一键全局旁路。

价格预设功能不属于本版本，未进入运行时或发布包。

## 数据、安全与隐私

- 新增 `BiaoGe.BGNext.equipmentFilters[realmId][player].enabled` 布尔值，只保存当前角色是否临时启用装备过滤。
- 拍卖职业颜色复用当前团队运行时已经建立的 `BG.raidRosterInfo`；不新增持久化团队名单、玩家历史或画像。
- 本版本不新增或修改插件消息、聊天发送、接收对象、外部传输或遥测。
- 不读取或迁移已废止的自动出价价格配置。

## 来源与基线

- 本次未研究、复制或打包第三方插件源码、配置、数据库、文案或素材。
- 修改的 BGLite 基线运行文件逐项登记到 `docs/baseline/BGNext-overrides.sha256`，原始 188 文件基线清单不变。
- 发布包继续由 `tools/build-release.ps1` 根据 TOC/XML 加载图生成，并排除历史记录、旧整表接收、测试、工具和开发文档。

## 验证与兼容状态

- Lua 自动测试通过：`passed=49 failed=0`。
- Lua 5.1 语法检查通过：4 个本次变更涉及的 Lua 文件均可编译。
- 基线完整性通过：188 个上游基线文件，包含 30 个明确登记的 BGNext 覆盖文件。
- `git diff --check` 通过。
- 发布包内容审计通过：226 个运行时文件；ZIP 只有 `BGNext/` 根目录，包含 `BGNext/BGNext.toc`，版本为 0.3.1，不包含旧 BGLite 包路径、已禁用历史模块、测试、工具或 Git 文件。
- 当前自动化测试覆盖短名／全名身份匹配、团队名单职业解析、颜色回退、过滤关闭／恢复和表格快捷键调用。
- 永久 60、TBC、Titan／时光服、熊猫人和正式服尚未对本次新增交互完成游戏内验证；网易 DD 文案不得把自动化覆盖表述成全客户端实机验证。
