# 角色总览非满级角色显示开关设计

日期：2026-09-19
状态：已由维护者确认

## 目标

角色总览设置新增“显示非满级角色”复选框，默认不勾选。角色总览默认只显示当前客户端版本已满级的角色，避免 1 级仓库号等长期占据窗口。

## 行为边界

- 满级值只使用本插件现有的实际客户端等级上限 `BG.fullLevel`，不在新功能中另外硬编码版本等级。`BG.fullLevel_RoleOverview` 是旧角色总览的最低展示等级，不用于判断满级。
- 未勾选时，只有等级为有效数字且大于等于当前版本满级值的角色进入可见投影。
- 勾选后立即显示所有已保存角色，包括非满级和旧快照。
- 过滤只发生在角色总览的纯投影层；不删除快照，不停止采集，不改动用户保存的角色顺序。
- 角色后续升到满级并刷新快照后自动出现。
- 设置保存为布尔值；字段缺失、损坏或老用户升级时均按“不显示非满级角色”处理。
- 当前客户端没有可用的满级值时，安全降级为不过滤，不把全部角色误隐藏。

## 设置与数据

开关位于“设置 → 角色总览”，与“启用角色总览”分开。建议保存为 `BiaoGe.BGNext.settings.roleOverviewShowNonMaxLevel`。它只是本地显示偏好，不会通信或上传。

## 验收条件

1. 无旧设置时，1 级与其他非满级角色不显示，满级角色正常显示。
2. 勾选开关后，非满级角色立即恢复；取消后立即隐藏。
3. 当前服务器和 Shift 全服务器两种视图使用相同过滤规则。
4. 可见角色数、黑灰交替行、合计值和窗口高度全部基于过滤后角色重算。
5. 隐藏后快照、排序数据和其他客户端版本数据保持不变。
6. 拍卖、交易、欠款、账单和其他角色总览设置的既有回归全部通过。
