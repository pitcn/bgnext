# BGNext UI 语义层级统一设计

## 目标

在不改变大屏表格密度、透明度和数据逻辑的前提下，统一按钮、章节标题、Boss 名与价格列表的视觉语言，消除“不同模块打补丁拼在一起”的感觉。

## 方案比较

1. 全量重做所有控件：最统一，但会碰触大量旧客户端模板和表格输入框，风险过高。
2. 只改截图中的几个颜色：成本低，但下一处旧模块仍会重新出现同类问题。
3. **语义令牌收口（采用）**：在现有 `UIStyle` 增加正文、次级、品牌、警告和列表状态；各模块只声明内容角色，不再自行挑颜色。

设计骨架采用 VoltAgent `awesome-design-md` 中 Linear 规范的单一强调色、暗色表面阶梯、细边框和 14px 按钮层级；品牌强调色仍使用 BGNext 青色，不复制 Linear 的紫色品牌身份。

## 视觉规则

- 品牌青只用于选中项、章节标题和当前导航。
- 正文使用浅灰白，说明与普通 Boss 名使用灰蓝。
- 装备品质色、角色职业色、完成标记和危险操作色保留，因为它们有明确含义。
- 普通共享按钮字号由 15 调整为 14；主导航保持 15。
- 角色总览的章节标题改为品牌青，列标题统一浅灰白；角色名继续使用职业色。
- 账本普通 Boss 名统一灰蓝；“总结/工资”用品牌青，“我漏记的装备”用柔和警告色。悬停仍变亮。
- 价格预设 Boss 列表的普通项弱化边框，选中项才使用品牌青边框。
- 团长价格列表不再重复显示“基础/单件”；直接显示 `X G`。没有单件覆盖价时隐藏红叉，并用次级文字显示继承价格。
- 个人心理价未设置时显示长横线并隐藏红叉；已设置时显示 `X G`。

## 边界

- 不重排账本、对账、心愿清单和价格预设的几何结构。
- 不替换 Blizzard 输入框模板，不增加逐行纹理或 OnUpdate。
- 不改装备品质色、职业色、数据读取、保存格式或团队通信。
- 经典外观继续走原有颜色和按钮逻辑；本轮语义统一只在现代预览外观生效，角色总览自身的新配色除外。

## 验收

- 现有 Lua 测试、基线安全测试全部通过。
- 纯函数测试覆盖语义色、价格显示和清除按钮可见性。
- 源码审计确认价格页仍维持固定对象预算，没有新增 OnUpdate、网络或数据写入路径。
