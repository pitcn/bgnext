# 熊猫人角色总览活动列设计（Issue #63）

## 结果

角色总览增加四个互不关联、默认关闭的熊猫人专属资源列：天神首胜、农场收菜、四天神、斡耳朵斯。它们沿用现有按版本列设置，不影响其他客户端。

## 证据与读取

- 天神首胜：枚举客户端随机地下城，匹配本地化名称中的“天神 / Celestial”，读取 `GetLFGDungeonRewards` 的 `doneToday`；按 `GetQuestResetTime` 过期。
- 四天神：读取官方 BGLite 2.4.2 已声明的世界首领任务标记 33117；按客户端每周重置时间过期。
- 斡耳朵斯：读取官方 BGLite 2.4.2 已声明的世界首领任务标记 33118；按客户端每周重置时间过期。
- 农场收菜：未找到能证明四风农场“全部收完”的可靠公开客户端接口。该列只显示未知和原因，不从位置、登录时间、背包变化或普通日常任务推断。

暴雪国服资料确认“每日首次天神地下城奖励”与轮换日常任务是两件事，并确认四天神和斡耳朵斯为永恒岛世界首领：

- https://wow.blizzard.cn/news/20260107/40565_1280577.html
- https://wow.blizzard.cn/news/24264421/index.html

## 数据边界

只读当前登录角色，保存最新状态、观察时间和重置时间。重置即删除，不保存每日/每周历史，不读其他玩家，不通信。缺 API、缺目标地下城、返回值异常或记录过期均显示未知或隐藏，绝不改写成未完成。

## 验证边界

自动测试覆盖目录隔离、日/周读取、缺 API、未知状态、重置过期、存储白名单和投影。真实客户端的 LFG 返回形状、名称、任务标记刷新时机和周重置 API 仍须实机验证，因此兼容性等级保持“代码覆盖、自动化测试通过；待实机验证”。
