# 隐私政策

## 适用范围

本政策说明 BGNext 仓库接受的插件数据处理边界。具体版本的数据行为还应结合对应 Release Notes、代码审查和平台审核结果理解。

## 核心原则

- **本地优先：**能在玩家本地完成的功能，不把数据发送到游戏外。
- **最小必要：**只处理实现明确功能所必需的数据。
- **公开透明：**数据类别、用途、保存位置、接收对象和触发条件必须可查。
- **用户控制：**游戏外导出或传输必须由用户主动、手动触发。
- **默认拒绝：**无法解释必要性或无法合理排除风险的数据处理不予合并。

## 当前 BGLite 2.4.0 基线

当前基线通过 `BGLite.toc` 声明本地 SavedVariables 数据入口 `BiaoGe`，用于保存插件配置和相关游戏记录。数据随《魔兽世界》插件机制保存在玩家本地客户端中。

BGLite 的团队拍卖、交易和协作功能会使用游戏内团队、密语及插件消息频道，在参与协作的玩家之间传递必要信息，可能涉及：

- 角色名及团队身份；
- 物品、拍卖状态、出价或金额；
- 交易状态、账目协作信息；
- 插件版本和协议消息。

这些消息用于当前游戏会话中的团队协作，接收方通常是团队成员或明确的密语对象。它们不是向网站、云服务或其他游戏外接收方自动上传。玩家仍应避免在公开频道发送不必要的个人信息。

## 禁止行为

项目禁止：

- 未经许可采集、保存或传播账号、设备、聊天、战斗、交易或其他可识别信息；
- 在插件加载、角色登录、进入副本或其他游戏行为发生时自动向游戏外上传或同步；
- 使用隐藏标识关联不同角色、账号、设备或游戏会话；
- 未披露的遥测、统计上报、远程日志或错误上传；
- 将本地记录用于与玩家预期无关的画像、营销、排名或商业用途；
- 要求玩家提供密码、验证码、身份证件、支付信息或其他与插件功能无关的敏感数据。

## 主动导出与游戏外传输

如未来功能确需导出或向游戏外接收方传输数据，必须同时满足：

1. 由用户主动、手动触发；
2. 触发前清楚展示将包含的数据；
3. 说明用途及具体接收方；
4. 说明保存时间、公开范围和主要风险；
5. 提供取消操作，且取消后不产生传输；
6. 能删除、匿名化或聚合的数据不得保留可识别形式。

仅提供复制文本的按钮也属于导出功能，必须清楚展示复制内容。不得把聊天记录、账号标识或其他无关数据混入导出结果。

## 日志、截图和问题报告

提交 Issue、Pull Request 或安全报告前，请删除或遮盖：

- 真实姓名、手机号、邮箱、地址和证件信息；
- 战网账号、登录凭据、验证码和恢复信息；
- 不必要的角色名、公会名、聊天内容和玩家备注；
- 设备路径中可能出现的用户名；
- 与问题复现无关的交易和财务信息。

维护者发现公开内容包含敏感数据时，可以先隐藏、编辑或删除相关内容，再联系提交者补充脱敏材料。

## 政策变更

新增数据类别、保存位置、接收对象、消息协议或游戏外通信能力属于重大变更，必须通过独立 Pull Request 说明，并在对应 Release Notes 中披露。重大变更不得仅通过静默更新本文件生效。

## 联系方式

普通隐私疑问可提交 GitHub Issue；可能导致玩家身份暴露或可被利用的问题，应按 [安全政策](../../SECURITY.md) 私密报告。
