# BGLite 2.5.4 价格预设兼容研究

日期：2026-09-02
研究对象：用户本机提供的 BGLitePlus 增强版 2.5.4
研究范围：表格装备快捷操作、起拍价方案和旧价格字符串导入

## 研究边界

本记录按 ADR-0003 编写。研究副本只作为只读输入，用于确认玩家可见行为和互操作需求；没有复制、改写或打包其源码、界面素材、内部命名、注释或数据表。

## 玩家可见行为与兼容事实

- 表格装备的 Alt+右键可以按已保存的单件起拍价直接开始拍卖，普通打开拍卖窗口时仍允许临时修改价格。
- 玩家希望能从表格装备直接修改该装备的预设起拍价，而不必先进入完整价格管理页。
- 旧版价格导出文本只表达一个团本中的单件价格集合，不包含 BGNext 的客户端家族、多方案名称或基础价信息。
- 旧文本由玩家主动复制、粘贴和确认；导入不需要自动读取剪贴板、聊天内容或其他插件的 SavedVariables。

## 对 BGNext 的派生需求

1. 基础价和单件价在输入框失去焦点时提交，避免可见值与实际保存值分离。
2. Alt+右键必须先解析并写入当前有效预设价，再复用 BGNext 现有拍卖按钮的权限、参数和发送流程；解析失败时不得直接开拍。
3. Ctrl+右键打开 BGNext 自己的单件价格编辑弹窗，普通右键清除行为保持不变。
4. 团长导入器单向接受旧版单团本价格文本，将其转换为一套新的、经过上限和已知物品校验的 BGNext 方案。
5. 旧格式没有基础价，转换时使用当前方案的基础价作为未单独设置装备的回退值，并在预览中明确标注旧版来源。

## 独立实现与明确排除

BGNext 使用自己的 `AuctionPriceCodec`、`AuctionPriceStore`、`AuctionPriceRuntime` 和导入预览流程实现上述需求。旧文本只作为兼容输入，BGNext 不生成旧格式，不读取或迁移参考插件的存档，不保留旧提示字段，也不采用参考插件的 UI 结构、批量过滤布局或函数组织。转换后只写入数据清单已经登记的 `leaderAuctionPricePresets` 字段。
