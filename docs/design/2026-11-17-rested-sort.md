# 角色总览自动排序与休息经验百分比

本轮维护者明确要求作为实施规格，覆盖历史设计中的“不新增自动排序”限制。
默认排序保留已有手动顺序；无手动顺序时仍为当前服务器、服务器 ID、名字。
账号级设置提供默认、职业-装等-名字、装等降序、等级降序、名字、最近更新。
职业采用固定客户端职业 ID 顺序；装等、等级、更新时间降序，缺失值最后；
同键按名字、服务器 ID 决定。自动模式覆盖手动顺序但不删除它；选择默认可恢复。
设置页显示六个选项按钮，当前选项锁定游戏原生按钮高亮，不在文字中添加特殊字符；自动模式下手动上移/下移禁用，删除可用。

只采集当前登录角色，百分比为 GetXPExhaustion / UnitXPMax(player) × 100，
记录独立观察时间和 IsResting 布尔值。API 成功返回 nil exhaustion 代表 0；
缺失、异常或零分母留空；兼容已有现代 API 后备路径。不上报、不发送消息。
登录、经验/休息状态变化和登出更新；登出同步采集，不等延迟计时器。
金币和装备更新不改变休息经验观察时间。登录该角色后实际快照覆盖旧估算基准。
只存最后快照，估算只存在视图，不写回历史或存档。

离线角色以最后观察为基准：休息区 5 百分点/8 小时，野外 1.25 百分点/8 小时，
上限 150%，标“约”；缺少休息区或观察时间则不增加，时钟回退不扣减。
该普通规则的参考是维护者评估报告；Forever 可能另有营地、倍率或服务器规则，
未实机验证，必须明确披露。参阅普通规则说明：
[休息经验概述](https://www.wowhead.com/guide/rested-experience-bonuses-leveling-warcraft)。
本轮不引入其他种族/模式/活动的倍率猜测。

所有现有客户端目录声明该列、默认显示，显式隐藏继续生效，API 缺失留空。
不提升任何客户端整体兼容性声明或解除现有总览可用性门槛：Wrath/Cata
目录仍 unverified，探索服仍沿用既有总览禁用规则。
逐角色等级 <10 或 >= 当前客户端上限时留空；当前上限取客户端 API/常量，
缺少可靠上限也留空，不硬编码满级等级，不把当前角色是否满级套用给其他行。

原创实现只依据现有 BGNext 模块与游戏 API；未读取 BiaoGe 源码/素材，
未读取游戏 WTF/SavedVariables 文件。只修改两份已有本地化基线覆盖文件，
逐文件复核后仅更新各自哈希；TOC、消息协议和数据命名空间不变。

## 2026-11-18 离线快照修正

登出等刷新中，休息 API 不可用、异常或经验分母无效时，采集器没有新观察，
不能以空值覆盖该角色上次有效的百分比、观察时间和休息区状态。完整刷新与
分区刷新统一保留这三个已有字段；有效观察（包括真实 0%）仍整体替换。
无休息字段的旧角色继续留空，不迁移、不推算原始经验值。离线增长、150%
上限、“约”、10 级门槛与满级隐藏规则保持不变。

模拟回归覆盖时光服与无限服：A 登录采集、登出 API 分母失效、B 登录并加载
本地快照后 A 仍显示估算值。另覆盖不可读完整刷新、异常 API、旧记录留空、
成功登出更新与真实零值。未读取 WTF，未研究或复用第三方插件代码；本次
实际客户端复现与安装后验证仍待实机完成，不能据模拟结果宣称已实机通过。
