# BGNext 入口交互统一设计

日期：2026-08-29
状态：待维护者复核书面规格
关联：GitHub Issue #5

## 目的

BGNext 的常用入口应符合玩家对 WoW 插件的通常预期：左键执行主要动作，右键提供更多选择，中键和组合键只能作为可选快捷方式。玩家不应为了打开角色总览而先猜到悬停、中键或 Ctrl+左键操作。

本设计统一三个入口：小地图按钮、主窗口右下角“角色总览”按钮和独立按键绑定。它只调整入口交互，不改变角色总览的数据、布局、刷新、隐私或版本目录。

## 交互规则

### 小地图按钮

| 操作 | 行为 |
| --- | --- |
| 左键 | 打开或关闭金团表格主窗口，保持现有主要操作不变。 |
| 右键 | 打开 BGNext 入口菜单，不再直接打开设置。 |
| 中键 | 在角色总览可用时打开或关闭固定角色总览；不可用时静默无操作。它是兼容快捷方式，不是主要教学路径。 |

右键菜单按以下顺序显示：

1. 打开/关闭金团表格；
2. 打开/关闭角色总览；
3. 设置。

菜单文字应根据当前窗口状态使用“打开”或“关闭”。“角色总览”只在当前客户端目录可用且功能未禁用时显示；探索赛季及未支持客户端不显示该项。选择“设置”打开设置页，并沿用当前关闭主窗口的行为。

菜单使用游戏内 UI，不引入外部素材、通信、持久化历史或新的 SavedVariables。菜单关闭、ESC 和点击空白处等行为沿用暴雪菜单规范。

### 主窗口右下角“角色总览”按钮

| 操作 | 行为 |
| --- | --- |
| 左键 | 打开并固定角色总览；固定窗口已打开时再次点击关闭。 |
| 悬停 | 延迟 0.2 秒后显示未固定的快速预览。 |
| 离开 | 只关闭未固定预览；固定窗口保持显示。 |
| 右键 | 打开设置，并定位到角色总览设置。 |
| 中键、Ctrl+左键 | 保留为固定窗口开关的兼容别名，但不作为主要操作说明。 |

如果鼠标已经触发预览，随后左键点击应把当前预览固定，而不是先关闭再创建窗口。所有入口必须复用同一个角色总览窗口，不能产生叠加窗口。

悬停预览仍有价值，因为它允许玩家快速查看 CD 后直接移开鼠标；但它只是辅助能力，不能再成为唯一的普通鼠标入口。短暂经过按钮时不应立即弹窗，因此增加轻微延迟。

### 独立按键绑定

新增与主表格绑定完全独立的“打开/关闭角色总览”动作。它与小地图中键、右下角左键调用同一个安全切换入口：

- 可用时切换同一个固定角色总览；
- 不可用或功能被禁用时静默无操作；
- 不打开主表格；
- 不改变 `/bgn role` 的现有行为。

简体中文、繁体中文和英文显示名必须与动作一致。实现应调查当前客户端是否允许隐藏不可用的静态绑定项；无论按键设置中能否动态隐藏，运行时都必须失败关闭，不能打开空白或误导窗口。

## 状态与职责

角色总览入口模块继续作为唯一交互协调者，负责：

- 判断角色总览是否可用及是否启用；
- 切换预览、固定和隐藏状态；
- 向小地图菜单、窗口按钮、快捷键和命令提供同一公开入口。

小地图模块只负责识别鼠标按键和展示菜单，不自行创建角色总览窗口。按键绑定只调用公开入口，不直接操作窗口内部状态。这样可以避免不同入口各自维护一套开关逻辑。

## 安全与兼容边界

- 不新增数据采集、网络通信、插件消息、聊天发送或遥测。
- 不新增或迁移 SavedVariables。
- 不改变角色快照、团本 CD、货币、专业或装备字段。
- 不改变 BGLite 团队拍卖协议。
- 主表格左键入口及现有主表格快捷键保持不变。
- `/bgn role`、右下角入口、悬停预览、拖动、刷新、设置和 ESC 关闭继续使用原有窗口。
- 探索赛季等角色总览不可用的客户端不显示角色总览窗口或小地图菜单项。

## 验收标准

- 小地图左键仍然只切换金团表格。
- 小地图右键最多显示三个入口；角色总览不可用时只显示主表格和设置。
- 小地图中键只作为角色总览兼容快捷方式。
- 右下角角色总览按钮左键可以直观地打开、固定和再次关闭同一窗口。
- 悬停预览有轻微延迟，快速经过不会闪窗；移出后只关闭未固定预览。
- 预览后左键会固定现有窗口，不产生重复或闪烁。
- 右下角按钮右键准确进入角色总览设置。
- 独立角色总览快捷键与主表格快捷键互不影响。
- 所有入口在角色总览不可用或禁用时安全降级。
- 自动化测试覆盖鼠标映射、菜单项与顺序、状态切换、悬停延迟决策、重复窗口防护、绑定声明和不可用客户端。
- Lua 测试、基线校验、差异检查和发布包审计全部通过。
- 游戏内实测至少覆盖小地图三种按键、右下角按钮、按键设置、ESC，以及支持/不支持角色总览的客户端各一种。

## 不在本次范围

- 修改角色总览内容、表格布局或版本数据。
- 正式服 Boss 级 CD。
- YY 号码复制。
- 多子账号角色汇总。
- 为小地图菜单增加交易、邮件、心愿清单等更多入口。
- 重新设计整个主窗口底部按钮栏。
