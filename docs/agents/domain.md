# Domain-document routing

BGNext is a single-context repository.

Agents must begin with the complete red-line rules in root `AGENTS.md` and `CLAUDE.md`. For implementation, also read the relevant approved specification under `docs/superpowers/specs/`, applicable policy files, ADRs, and the data inventory when those files exist.

An ADR records a durable architecture, licensing, privacy, protocol, or compatibility decision. A later decision supersedes an earlier one only when the new ADR says so explicitly. Private conversations are not repository documentation and must not be quoted or published.

If a required domain document is absent or contradicts the root red lines, stop and report the mismatch instead of inventing a rule or silently choosing the less restrictive interpretation.
